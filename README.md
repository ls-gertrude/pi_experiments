Rasperry Pi Projects
Hi! This is where I keep my hands-on embedded systems and IOT projects I've been building
With a rasperry pi 4, I've been able to explore how hardware interacts with code

What's inside?
*  "./camera_vision" - Computer vision projects using USB webcam and PIR motion sensors to detect movement and capture images.
* "./smart_home" - Physical security and automation scripts.One sends alerts to my phone straight through telegram!

What was used?
* Hardware - Rasperry pi 4, PIR Motion Sensors, 4x4 Matrix keypads, 16x2 LCD, Active Buzzers.
* Software - Python 3, Linux (Rasperry Pi OS)

I also safely stored my API keys and all other confidential and private information in a '.env' file so they aren't hardcoded
